# Test Plan — Public Demo Store

**Application:** https://www.saucedemo.com/ (third-party public demo, not owned by this portfolio)

**Objective:** Demonstrate reproducible UI automation using Playwright/Pytest and Selenium.

**In scope:** positive login, invalid credentials, required username, add/remove item, cart item, Selenium login smoke test.

**Out of scope:** production payment processing, private healthcare data, performance/security certification.

**Entry criteria:** internet access, compatible Python, browser dependencies installed, public demo reachable.

**Exit criteria:** all selected tests run, outcomes reviewed, any failures triaged.

**Risks:** third-party site changes, rate limits, browser/driver availability.

**Evidence:** pytest-html report generated locally under `reports/` after execution. No results are pre-claimed.
