# QA Automation Portfolio | A. Kanimozhi

**Python · Playwright · Pytest · Selenium · UI Regression Testing**

This is an **independent public-demo practice project**, created to demonstrate QA automation techniques for remote QA roles. It is **not** a repository of employer-owned code and does not claim to reproduce any confidential healthcare or Namostute application.

## Demo application

[Swag Labs / SauceDemo](https://www.saucedemo.com/) — public demonstration store. Public test credentials displayed by the site: `standard_user` / `secret_sauce`.

## Repository structure

```text
pages/                    Playwright page object
 tests/                   Playwright and Selenium test cases
 docs/                    Test plan and test-case catalog
 .github/workflows/       GitHub Actions Playwright workflow
 requirements.txt         Python dependencies
 pytest.ini               Markers and HTML report configuration
```

## Windows setup

1. Install Python 3.11 or 3.12 and Google Chrome.
2. Open PowerShell in this repository directory.
3. Run:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m playwright install chromium
python -m pytest -m playwright
```

If PowerShell blocks activation, use `.venv\Scripts\python.exe` instead of `python` in subsequent commands.

## Run Selenium tests

Selenium Manager normally resolves the ChromeDriver automatically when Chrome and internet access are available.

```powershell
python -m pytest -m selenium
```

## Run all tests

```powershell
python -m pytest
```

## Report

Open `reports/report.html` after a test run. This file is generated by pytest-html, and `reports/` is gitignored. **No tests are represented as executed or passing until actually run.**

## CI

Push this project to GitHub on the `main` branch. GitHub Actions will attempt Playwright tests on pushes and pull requests; the workflow can also be launched manually. Review the Actions run status and downloadable HTML report artifact for actual results.

## Quality practices demonstrated

- Page Object Model (POM) for reusable login actions
- Positive, negative, validation, and cart regression scenarios
- Explicit waits/assertions, pytest markers, teardown
- HTML reporting and GitHub Actions CI for Playwright
- Separate Selenium smoke test

## Limitations

Third-party demo UI may change. Selenium test requires local Chrome/ChromeDriver support. No sensitive patient data or private client artifacts are included.
